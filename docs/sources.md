# Источники и достоверность «Детства»

Проверены загруженные пользователем 19 HTML и ODS. Метаданные и SHA-256
каждого файла сохранены в `data/sources/manifest.json`. В игровые правила
включена только глава I; содержащиеся в загрузках поздние главы не перенесены.
Это проверка согласованности руководств, не независимая проверка по оригинальной игре.

В JSON каждого события и варианта есть `source`; у спорных вариантов — `notes`.
Нумерация строк ODS в ссылках начинается с 1, как в табличном редакторе.

## Что оказалось с ODS

Строки вложены в сворачиваемые группы. Чтение только непосредственных строк
листа ошибочно создаёт впечатление, что детства в файле нет. Экстрактор
обходит вложенные строки и разворачивает повторяющиеся ячейки, сохраняя колонки.

Однако **порядковые номера вариантов в таблице не совпадают с руководствами**.
Например, в «Прятках» первым стоит прибавление чуткости, тогда как первым
в подробном руководстве идёт плач, дающий силы. Автоматически сопоставлять
варианты по номеру нельзя. Нормализация выполнена по смыслу последствий.

| Расхождение | Принятое правило |
| --- | --- |
| «Стихи Глории»: в ODS отсутствует уход из комнаты | Добавлен по двум полным спискам: +10 сил |
| Урок фехтования: ODS не даёт +1 решительности | Прибавка включена: её указывают несколько руководств и подтверждают контрольные итоги |
| Смотреть на плавящихся солдатиков: ODS пропускает +5 сил | Включено по подробному руководству и руководству достижений |
| Требовать представить мать: ODS пропускает -1 к Грегору | Включено по подробному списку последствий |
| «Дразнить деда»: ODS дополнительно требует силы ≥ 0 | Принята только благодарность Глории, как в подробном 2909473230. Дополнительный порог остаётся спорным |
| Поцеловать меч: ODS добавляет +1 единства | Не применено: оба полных списка последствий прибавку не содержат. Нужна проверка в игре |
| Поцеловать меч: ачивмент-гайд пишет силы > 0, подробный гайд и ODS — ≥ 0 | Принят порог ≥ 0 |
| Просить урок фехтования: только ODS явно указывает силы ≥ 0 | Порог применён, но его независимое подтверждение отсутствует; отмечен в варианте |
| ODS содержит отдельное «Причастие брата и сестры» с -1 единства и -1 к Стефану | Не вставлено как обязательное изменение: событие не описано в полных списках, а момент и условность эффекта не установлены |

Исходные расхождения не затёрты: сравнить их можно в извлечённых JSON.
Нет оснований называть весь ODS ни полностью правильным, ни бесполезным.

## Допущения, которые ещё нужно проверить в игре

1. Начальные характер и силы — 0; единство 6, богатство 5, репутация 3;
   отношения с родными 1, с Грегором -1; смертей 0. Это строка 3 ODS.
   Итоговые семейные показатели не проверены независимо. Фоновые изменения
   вне выборов могут отсутствовать в реконструкции.
2. Дополнительные события срабатывают после достижения 4 соответствующего
   стата, затем возвращают к основной цепочке. Разные позиции в нескольких
   руководствах подтверждают зависимость от стата. Точные возрастные окна,
   особенно для необычно раннего получения порога, неизвестны. После
   последнего выбора причастия новые события не вставляются.
3. Нет неподтверждённых ограничений сверху/снизу и автоматических наказаний
   за низкие показатели. Например, -10 сил после разрешённого урока —
   подтверждённое поведение, а смерть от отрицательных сил не выдумана.
   Возможные ограничения остальных статов ещё не проверены.
4. Посмертные и дородовые диалоги без изменений статов опущены. Малая смерть
   отмечается счётчиком и свершением «По ту сторону».
5. Краткий контекст — редакторский пересказ по названиям и вариантам,
   не извлечение полного текста сцены. Дополнительные сюжетные факты не добавлялись.
6. «Не получить нужное свершение» и «проиграть игру» — разные вещи.
   Цели задаёт игрок через `--goal`. Оригинальный Game Over для детства
   из этих материалов не установлен; вымышленной концовки поражения нет.

## Проверка

Автотесты воспроизводят три описанных выше реальных маршрута и сверяют
итоговые показатели характера/сил; проверяют сдвиг положения дополнительных
событий, благодарность отдельно от отношений, условие ИЛИ и порог сил 0.
Воспроизводимая симуляция достигает всех 44 вариантов за 15 прохождений;
она проверяет достижимость **в модели**, а не полноту относительно игры.
Терминальный маршрут также пройден через ввод номеров, включая недостигнутую
личную цель. Эти проверки не устраняют перечисленные расхождения источников.

Showgamer по присланной ссылке возвращает через прокси 403; его текст
не получен и в подтверждения правил не включён. Загруженных материалов
хватило для этой версии детства; новые разрешения сети для её запуска не нужны.
